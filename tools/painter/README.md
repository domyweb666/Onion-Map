# 用電腦幫手機畫圖

手機上的洋蔥地圖把一張地圖底稿送到這台電腦，電腦叫 Codex CLI（登入你的 ChatGPT 帳號）畫成手繪風，畫好傳回手機。底稿上沒有路線、沒有字，也沒有你的資料。

## 第一次要先準備

1. 裝 [Node.js](https://nodejs.org/)，20 版以上。
2. 打開終端機，裝 Codex 並登入 ChatGPT：

```
npm install -g @openai/codex
codex login
```

## 怎麼開

雙擊這個資料夾裡的 `開始畫圖.cmd`。第一次會花一點時間裝東西，之後會印出一個 QR。

習慣用終端機的話，在這個資料夾打：

```
npm install
npm start
```

視窗要一直開著，電腦不要睡著。按 Ctrl+C 結束。

## 怎麼掃

手機打開洋蔥地圖，到「設定」的「畫圖」，掃電腦上的 QR。手機跟電腦要連同一個 Wi-Fi。

掃過一次就好，之後重開電腦也不用再掃。電腦換了網路、IP 變了的話要重掃一次。QR 只畫第一個網址，連不上的時候把下面別行貼到手機試試。

會跳出來問的兩件事都要按允許：

- **電腦**：Windows 防火牆第一次會問要不要讓 Node.js 連網路，按允許，至少勾「私人網路」。按錯了到「Windows 安全性」的「防火牆與網路保護」，點「允許應用程式通過防火牆」，把 Node.js 打勾。
- **手機**：iPhone 第一次會問要不要讓洋蔥地圖找區域網路上的裝置。按錯了到 iPhone 的「設定」，「隱私權與安全性」，「區域網路」，打開洋蔥地圖。

## 會用掉多少額度

吃的是你 ChatGPT 方案裡的 Codex 額度，不會另外收錢。額度用完那張會失敗，手機上會講，過一陣子再畫。

2026-11-25 用 ChatGPT Go 實際畫了一張：花 157 秒，每月額度從 19% 變成 22%。照這樣算一個月大概畫得了二、三十張，Codex 還有別的用途就更少。

同一張圖按了兩次只會畫一次，畫好還沒傳回手機的也不會重畫。畫到一半取消，已經用掉的額度拿不回來。

## 可以調的

| 設定 | 做什麼 |
|---|---|
| `npm start -- --new-token` | 換一組新密碼，舊的 QR 就不能用了，手機要重掃 |
| `PORT` | 換埠號，預設 8790 |
| `CODEX_MODEL` | 換模型，預設 `gpt-5.6-terra` |
| `ONION_FAKE=1` | 假畫圖：不叫 Codex、不吃額度，等 3 秒把原圖調個顏色傳回去 |
| `ONION_FAKE_MS` | 假畫圖等多久（毫秒） |

PowerShell 的寫法是 `$env:ONION_FAKE=1; npm start`。

## 東西放在哪

都在使用者資料夾的 `.onion-painter`：`token` 是密碼，`jobs` 是畫好的圖，滿一天自己刪掉。底稿畫完就刪。Codex 自己也會在 `.codex/generated_images` 留一份畫好的圖，那份要自己清。

使用者名稱是中文的電腦，畫圖當下的底稿會先放在公用資料夾的 `onion-painter-work`，因為 Codex 的工作資料夾要英文路徑。

一次畫一張，後面最多再排三張。關掉重開，畫好的還拿得到，沒畫完的會算失敗。

## 安全

- 區網走的是沒有加密的 http。在自己家的 Wi-Fi 開就好，不要在咖啡店或飯店開。
- 沒有密碼的人連不進來。QR 裡面就有密碼，不要給別人看。
- 手機只能送圖，畫圖的指令寫死在 `prompts.mjs`。Codex 只能寫那張圖自己的工作資料夾，環境變數裡的金鑰不會給它。
- 回給手機的錯誤訊息是固定的幾句話，細節只印在電腦的視窗。

## 給寫程式的人

介面寫在 `docs/模組約定.md` 的「畫圖服務的介面」。這裡多做的幾件事：

- `seconds`：還在排是等了幾秒，在畫是畫了幾秒，畫完或失敗是總共畫了幾秒。
- 還沒畫好就要圖回 409。找不到或滿一天回 404。不准的網頁來源回 403。
- 底稿每邊 256 到 2048，body 上限 12MB，PNG 或 JPEG。
- 成品尺寸看 Codex 當次怎麼生，常見 1024×1536，也可能是 1122×1402。要圖的那頭自己看寬高。
- 同一張底稿（kind、style、圖都一樣）還在排或還在畫，再送一次會拿到同一個 id。

`npm test` 用假畫圖模式跟一支假的 codex 跑，不吃額度。
