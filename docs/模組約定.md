# 模組約定（2026-11-25，分支 paint-cli）

給平行開發的人看。每個人只准動自己那一欄的檔案；要別人的檔案改東西，寫在回報裡，由主會話改。
不要 commit、不要 push、不要開 worktree。

## 怎麼接起來

`src/js/*.js`、`src/css/*.css` 照檔名順序接成一份塞進單檔 HTML（`npm run build`），全部在同一個全域範圍，不是 ES module。
跨檔可以直接用的全域：

- `$(id)`、`toast(文字, 毫秒)`、`esc(字串)`、`NATIVE`、`FS`（Filesystem）、`SHARE`、`CapX`、`h3`、`map`（MapLibre 4.7.1）、`maplibregl`
- `engine.state()`：`{ cells:{h3:[次數,最後毫秒]}, flights, gaps, points:[[秒,lat,lng,精度,'w'|'v'|'f']], days:{'YYYY-MM-DD':{t0,t1,walk,veh,fl,n,box:[西,南,東,北]}}, area, km:{walk,vehicle,flight}, ext:{} }`。`points` 只有最近 60 天；`days` 全部都在
- `dayKey(毫秒或秒)`、`await loadDay(key)` 讀某一天的點
- `ext(名字, 初值)` 拿自己的資料（會存檔、會進備份），改完叫 `extSave()`
- `kv.get/set/del/list`、`kvTry`、`kvSafeSet`、`kvJSON`：存檔櫃，值是字串。大圖用 base64 字串，放 `cards/`、`base/`、`tiles/` 前綴
- `engine.merge(另一個引擎的state, {日期:[點]})`、`createEngine(h3)`、`engine.summarize(點)`
- 掛勾：`hook.fix.push((f, r, quiet)=>{})`、`hook.rec.push(on=>{})`、`hook.tab.push(tab=>{})`、`hook.ready.push(()=>{})`
- 事件：`onion:steps`（足跡頁剛畫完）、`onion:wiped`、`onion:restored`（document 上）
- `loadAdmin()`、`townAt(adm, lng, lat)`、`titleOf()`、`dayLog()`、`kmText(km)`、`loadFrame(id)`、`CARD_UI`、`cartouche`、`haloText`、`go(tab)`、`render(true)`、`addSheets()`、`SHEET_TOP`、`SHEET_FADE`

自己的頂層名字要帶前綴，不要撞名（整份共用一個範圍）。會跟別人同名的東西用 IIFE 包起來。

## 畫面掛點（src/index.src.html 已經放好）

| id | 在哪 | 誰用 |
|---|---|---|
| `mapAsk` | 地圖頁，記錄列上方的一張卡（沒內容就隱藏） | 地點 |
| `mountDayCard` | 製圖頁，「今天這張」的內容 | 日卡 |

| `mountOffline` | 設定頁「離線地圖」段 | 匯入 |

介面規矩：CSS 只准用 `var(--d-*)`，沿用 `.section .group .row .lbl .val .meta .ttl .btn.primary/.secondary/.plain .foot .seg .empty`；一個畫面最多一顆 primary；觸控至少 44；兩塊不同性質的東西間距至少 `--d-space-6`。
多米的設計哲學：懶人化、少設定、低資訊密度、規則與公式不給使用者看、系統自己處理、話講白（台灣用語，不自創名詞，不用破折號，不用「不是 X 而是 Y」）。

## 畫圖服務的介面（電腦 CLI 與雲端後端一樣）

QR 內容：`onion://pair?u=<網址，含埠>&t=<密碼>&n=<電腦名稱>`，各值 encodeURIComponent。
每個請求帶標頭 `X-Onion-Token`。回應都是 JSON，錯誤是 `{error:'給人看的一句話'}`。

- `GET /ping` → `{ok:true, name, kind:'pc'|'cloud', engine:'codex'|'openai', left?:今天還能畫幾張}`
- `POST /paint` `{kind:'day'|'base', style:'pencil', image:'<PNG 或 JPEG 的 base64，1024x1536>'}` → 202 `{id}`；額度用完 429。提示詞由服務端保管，手機不送提示詞
- `GET /paint/<id>` → `{status:'queued'|'painting'|'done'|'failed', ahead, seconds, error?}`
- `GET /paint/<id>/image` → `{image:'<base64>', mime}`
- `DELETE /paint/<id>` → `{ok:true}`

送出去的底稿沒有路線、沒有文字、沒有使用者資料。路線與字都是手機上程式畫的。
