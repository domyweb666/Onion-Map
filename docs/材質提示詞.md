# 無縫材質生圖提示詞

路 B（程式拼貼）要五張正方形材質，程式會把它們像磁磚一樣鋪滿整塊區域。生好放到 `assets/textures/`，檔名照下面，重跑 `collage.py` 就換上去。

## 五張都要遵守的規則

- 一張圖只有一種材質，鋪滿整張，沒有邊框、沒有留白、沒有暈影，四個角跟中間一樣密。
- 正上方往下看（屋頂那張可以微微斜一點看得到屋頂面）。
- 不要有主角：沒有一棵特別大的樹、沒有一棟特別大的房子、沒有船、沒有字。
- 光線平均，不要一邊亮一邊暗，不要漸層。
- 解析度開最大，正方形，1024 以上，能 2048 更好。
- 每張單獨生，不要排成圖鑑表。
- AI 說的「無縫」通常沒有真的無縫，沒關係，程式會接邊。你只要確保圖裡沒有明顯的邊界或漸層。
- 風格參考附你的貼紙集或那張 AI 地圖，每張都附同一張。

共用的開頭（每個提示詞最前面都貼這段）：

```
seamless tileable texture, square, top-down view, colored pencil hatching with thin ink outlines on cream paper, same style as the attached reference, evenly distributed pattern with no focal object, no border, no vignette, no gradient, no text, fills the entire frame edge to edge
```

## 1. forest.png 森林

```
(共用開頭), dense forest canopy seen from directly above: many small overlapping round tree crowns in two or three greens with a few yellow-green ones, pencil strokes visible, tiny dark gaps between crowns, no ground, no path, no river, no single large tree
```

中文說明：一片樹冠，小小的、很多顆、互相疊，綠色兩三種夾一點黃綠，縫隙是深色，不要有地面、路、河。

## 2. water.png 海面

```
(共用開頭), open sea surface: blue colored pencil hatching with small hand-drawn wave marks scattered evenly, lighter and darker blue strokes, a few tiny white foam ticks, no coastline, no boat, no fish, no horizon
```

中文說明：藍色鉛筆排線的海，小波浪記號平均撒，不要岸、不要船。

## 3. urban.png 屋頂

```
(共用開頭), a dense old town seen from above at a slight angle: hundreds of small houses packed together, orange-red tiled roofs with pencil shading, cream walls, tiny windows, narrow crooked lanes between blocks, roofs all roughly the same small size, no main road, no river, no plaza, no church, no castle
```

中文說明：一整片小房子，橘紅屋頂、米白牆，房子都差不多小，巷子彎彎的，不要大馬路、河、廣場、教堂、城堡。

## 4. meadow.png 草地

```
(共用開頭), grassland: light yellow-green colored pencil hatching, short diagonal strokes, a few tiny tufts of grass and small dots scattered evenly, no trees, no flowers, no path, no rocks
```

中文說明：淺黃綠的排線草地，短斜線，偶爾小草叢和小點，不要樹、花、路、石頭。

## 5. paper.png 紙

```
seamless tileable texture, square, aged cream parchment paper surface, fine paper grain, very faint fibers and tiny speckles, a few subtle pale stains, evenly lit, no edges, no burn marks, no fold lines, no text, no vignette, fills the entire frame
```

中文說明：米白的舊紙，細細的顆粒和纖維，淡淡的污漬，不要燒焦邊、摺痕、暗角。這張不用附風格參考。

## 生好之後

- 存成 PNG，檔名就是 `forest.png`、`water.png`、`urban.png`、`meadow.png`、`paper.png`。
- 丟給我，我放進 `assets/textures/`，接邊、重拼、重切圖磚。
